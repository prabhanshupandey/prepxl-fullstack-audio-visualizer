# PrepXL Fullstack Audio Visualizer Assignment

This repository contains my submission for the PrepXL Fullstack Development assignment.

The project demonstrates a real-time audio-based web application with the following features:

- Circular audio visualizer built using React
- Live microphone input using the MediaStream API
- Real-time frequency analysis using the Web Audio API
- Speech recognition with live on-screen text display
- Voice-based responses for interactive demonstration
- Proper microphone start and stop handling to avoid repeated responses

A demo video is included to showcase the complete working flow of the application.

## Frontend
- Built using React
- Uses the MediaStream API to capture microphone input
- Uses the Web Audio API for frequency analysis
- Circular visualizer reacts live to sound data

## Backend / Logic
- Handles real-time speech interaction logic
- Designed for low latency and smooth responsiveness

## How to Use
1. Clone or download this repository
2. Run the frontend and backend
3. Enable the microphone
4. Speak and observe visualization + text output
